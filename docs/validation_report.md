## How much weight to give these numbers

The labels, the data and the rules share one author, so a perfect score shows the rules match their own specification. It is not an estimate of performance on real data. An independent review found 27 issues in a version that already scored 1.0.

The more useful evidence is that the checks can fail. The test suite corrupts data on purpose and confirms the validators catch it, and it moves money between invoices to prove reconciliation notices. 18 structural checks (S01, S03, S04) repeat rules the schema already enforces, so they can only fail for data loaded by another route. The bugs found along the way are listed in `decisions.md`.
